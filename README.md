# Beginner C++ Projects

This repository contains three small console programs written in C++:

- `Electricity Bill Calculator.cpp` calculates an electricity bill from the customer's name and units consumed.
- `Grade_calculator.cpp` calculates the average of five subject marks and assigns a grade.
- `Shopping_Cart.cpp` calculates the total and highest price from five products.

## Requirements

- A C++ compiler such as g++, MinGW, or Visual Studio

## Build and run

From this directory, compile any program with:

```bash
g++ "Electricity Bill Calculator.cpp" -o electricity_bill
./electricity_bill
```

```bash
g++ "Grade_calculator.cpp" -o grade_calculator
./grade_calculator
```

```bash
g++ "Shopping_Cart.cpp" -o shopping_cart
./shopping_cart
```

On Windows, run the resulting executable with `.\electricity_bill.exe`, `.\grade_calculator.exe`, or `.\shopping_cart.exe`.
